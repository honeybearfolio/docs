## Release notes

Released: 2026-11-21

## 🚀 Features

- Add monthly budget health, active goal progress and scheduled transactions in dashboard, and extend information on PDF reports ([#921](https://github.com/honeybearfolio/HoneyBear-Folio/pull/921))
- Add budget section ([#918](https://github.com/honeybearfolio/HoneyBear-Folio/pull/918))
- Add various PDF reports like Net Worth, Balances, Cash Flow, etc. ([#898](https://github.com/honeybearfolio/HoneyBear-Folio/pull/898))

## ✨ Enhancements

- Add capability to archive accounts, assets, liabilities ([#891](https://github.com/honeybearfolio/HoneyBear-Folio/pull/891))

## ⚡ Performance Improvements

- Improve performance on PDF generation and FIRE simulations ([#919](https://github.com/honeybearfolio/HoneyBear-Folio/pull/919))
- Improve database performance when using LLM mode ([#917](https://github.com/honeybearfolio/HoneyBear-Folio/pull/917))
- Share one in-flight read instead of calling get_all_transactions from every screen ([#916](https://github.com/honeybearfolio/HoneyBear-Folio/pull/916))
- Stop rescanning the ledger to display account balances ([#915](https://github.com/honeybearfolio/HoneyBear-Folio/pull/915))
- Do not block first paint on daily prices ([#914](https://github.com/honeybearfolio/HoneyBear-Folio/pull/914))
- Improve performance when loading dashboard ([#912](https://github.com/honeybearfolio/HoneyBear-Folio/pull/912))
- Add pagination when querying transactions ([#911](https://github.com/honeybearfolio/HoneyBear-Folio/pull/911))
- Compute holdings in SQL instead of shipping every transaction ([#909](https://github.com/honeybearfolio/HoneyBear-Folio/pull/909))
- Keep one SQLite connection and add the list index ([#907](https://github.com/honeybearfolio/HoneyBear-Folio/pull/907))

## 🐛 Fixes

- Fix some values being stored in localstorage instead of database that need to persist across files ([#925](https://github.com/honeybearfolio/HoneyBear-Folio/pull/925))
- Fix chart colors to avoid using background color ([#923](https://github.com/honeybearfolio/HoneyBear-Folio/pull/923))
